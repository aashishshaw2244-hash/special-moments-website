# Special Moments Website 💖

A beautiful, interactive girlfriend appreciation website with custom animations, heartfelt messages, and magical effects.

## Features

- 🎨 **Beautiful Gradient Backgrounds** - Smooth animated gradients throughout the site
- ✨ **Custom Animations** - GSAP-powered smooth animations and transitions
- 💖 **Interactive Elements** - Hover effects and interactive cards
- 🎯 **Multi-Page Experience** - Three-page journey with different themes
- 📱 **Responsive Design** - Works on all devices (desktop, tablet, mobile)
- 🌟 **Floating Elements** - Magical floating emojis and hearts
- 💝 **Memory Cards** - Display special moments with beautiful cards

## Pages

### 1. **index.html** - Welcome Page
   - Custom cursor effect
   - Typing animation for greeting
   - Floating elements
   - Call-to-action button to proceed

### 2. **cause.html** - Reasons Page
   - Display reasons/messages one by one
   - Custom heart cursor
   - Gif overlays on hover
   - Counter showing progress
   - Transitions to next page when all reasons are revealed

### 3. **last.html** - Memories Page
   - Memory cards with images
   - Sparkle effects
   - Floating hearts
   - Final heartfelt message
   - Beautiful gradient background

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom animations, gradients, and transitions
- **JavaScript** - Interactive functionality
- **GSAP** - Advanced animation library
- **Google Fonts** - Custom typography

## Setup Instructions

1. Clone or download this repository
2. Add your images (d1.jpg, d2.jpg, d3.jpg, gif1.gif, gif2.gif) to the project folder
3. Open `index.html` in your web browser
4. Enjoy the experience! 💕

## Customization

### Change Names
- Edit the titles in HTML files
- Update the greeting text in `script.js`
- Modify messages in `cause.js` reasons array

### Change Images
- Replace d1.jpg, d2.jpg, d3.jpg with your own images
- Update gif1.gif, gif2.gif with your own GIFs

### Change Colors
- Modify gradient colors in CSS files
- Change the primary color (#ff69b4 is pink) to your preference

### Add More Reasons
- Edit the `reasons` array in `cause.js`
- Add new objects with `text`, `emoji`, and `gif` properties
